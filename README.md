\*\*Дисципліна:\*\* Системне програмування  

\*\*Виконала:\*\* Кісельгова Ксенія, ТТП-31



\## Мета роботи



Дослідити продуктивність програми мовою C++ за допомогою інструментів `perf`, `/usr/bin/time` та FlameGraph, проаналізувати асемблерний код і порівняти результати виконання до та після оптимізації компілятором.



\## Опис програми



Програма виконує 100 мільйонів обчислень синуса та 100 мільйонів обчислень квадратного кореня.



Основні функції:

\- `calculateSin()` — обчислення синусів.

\- `calculateSqrt()` — обчислення квадратних коренів.

\- `processData()` — виклик обчислювальних функцій та підсумовування результатів.

\- `main()` — запуск обчислень і вимірювання часу виконання.



Для порівняння використовуються два рівні оптимізації: `-O0` та `-O3`.



\## Використані технології



\- C++ / GCC

\- Ubuntu Linux

\- Linux perf

\- GNU time

\- FlameGraph

\- Intel x86-64 Assembly



\## Компіляція та запуск



Компіляція без оптимізації:



```bash

g++ -O0 -g -fno-omit-frame-pointer main.cpp -o program\_O0

```



Компіляція з оптимізацією:



```bash

g++ -O3 -g -fno-omit-frame-pointer main.cpp -o program\_O3

```



Запуск:



```bash

./program\_O0

./program\_O3

```



\## Основні результати



За результатами вимірювань `perf stat -d:



| Показник | -O0 | -O3 |

|---|---:|---:|

| Час виконання | 4,170 с | 3,913 с |

| CPU cycles | 12 021 781 032 | 11 224 565 073 |

| Instructions | 16 713 067 298 | 14 508 036 928 |

| IPC | 1,39 | 1,29 |



Оптимізація `-O3` скоротила час виконання приблизно на \*\*6,2%\*\*, а кількість інструкцій — на \*\*13,2%\*\*.

\## Висновок



У результаті виконання лабораторної роботи досліджено характеристики виконання програми, побудовано FlameGraph, проаналізовано асемблерний код та проведено порівняння рівнів оптимізації `-O0` і `-O3`.



Отримані результати підтверджують, що оптимізація компілятора може скоротити кількість виконуваних інструкцій і час роботи програми.
